# PrecisionPro

پلتفرم آموزشی فارسی و راست‌چین ابزار دقیق و سیستم کنترل؛ یک برنامهٔ React، TypeScript و Vite با داده‌های محلی و بدون نیاز به سرویس خارجی.

## امکانات

- دانشنامهٔ ۳۶ فصلی، با جداسازی حوزه‌های ابزار دقیق و سیستم کنترل
- توضیح فصل‌ها و سرفصل‌ها، جست‌وجو و لینک منابع
- مسیر یادگیری مرحله‌ای با ثبت پیشرفت روی همین دستگاه
- آزمون تعیین سطح از هر دو حوزه و ۳۶ تمرین متصل به فصل‌ها
- جعبه‌ابزار محاسبات سیگنال، جریان، فشار، دما، قانون اهم و حجم مخزن
- رابط فارسی RTL، فونت محلی Vazirmatn و قابلیت نصب از طریق PWA manifest و service worker

## اجرا و بررسی محلی

نیازمندی: Node.js 22 یا جدیدتر

```bash
npm ci
npm run dev
npm run lint
npm run build
npm run preview
```

## بارگذاری دستی در GitHub

1. در GitHub یک repository خالی بسازید؛ اگر می‌خواهید انتشار خودکار انجام شود، شاخهٔ پیش‌فرض را `main` بگذارید.
2. در repository، از **Add file → Upload files** استفاده کنید و این موارد را از پوشهٔ پروژه بارگذاری کنید:
   - پوشه‌های `src` و `public`
   - پوشهٔ `.github` (شامل workflow انتشار)
   - فایل‌های ریشه مانند `index.html`، `package.json`، `package-lock.json`، `vite.config.ts`، `tsconfig*.json`، `eslint.config.js`، `.gitignore` و `README.md`
3. تغییرات را روی شاخهٔ `main` ثبت کنید.
4. در repository به **Settings → Pages** بروید و **Source** را روی **GitHub Actions** قرار دهید.
5. workflow با نام **Deploy PWA to GitHub Pages** پس از ثبت تغییرات اجرا می‌شود. نشانی سایت پس از موفقیت در تب **Actions** یا **Settings → Pages** نمایش داده می‌شود.

از پوشهٔ ریشهٔ workspace یعنی `C:\Users\20-pc\Documents\instrument` بارگذاری کنید. **`node_modules` و `dist` را بارگذاری نکنید**: وابستگی‌ها در GitHub Actions نصب و خروجی سایت از سورس ساخته می‌شود. پوشهٔ `.github` را هم جا نیندازید، چون workflow انتشار در آن است.

## ذخیره‌سازی و منابع

پیشرفت مطالعه روی همان مرورگر و دستگاه ذخیره می‌شود و بین دستگاه‌ها همگام نیست. مطالب آموزشی برای یادگیری هستند؛ برای طراحی و کار عملی، استاندارد رسمی، دیتاشیت سازنده و مدارک تأییدشدهٔ پروژه را ملاک قرار دهید.
